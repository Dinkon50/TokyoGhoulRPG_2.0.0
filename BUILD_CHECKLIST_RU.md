# Сборка Tokyo Ghoul RPG 1.1.1

1. Требуется 64-bit JDK 17.
2. Для Windows можно запустить BUILD_WINDOWS.bat. Скрипт предпочитает C:\Program Files\Java\jdk-17.0.3, если эта папка существует.
3. В конце ожидается BUILD SUCCESSFUL и build\libs\tokyoghoulrpg-1.1.0.jar.
4. Эта версия исправляет ошибку ForgeGradle/Gradle `repository ... was added by plugin` и не использует `FAIL_ON_PROJECT_REPOS`.
