# Tokyo Ghoul RPG — Forge 1.20.1

Это исходный проект мода для Minecraft Java 1.20.1 + Forge.

## Сборка на Windows 11

1. Установите Java 17.
2. Распакуйте проект НЕ в OneDrive, например `C:\TokyoGhoulRPG`.
3. Запустите `BUILD_WINDOWS.bat`.
4. Скрипт сам скачает Gradle 8.8 и запустит сборку.
5. После успешной сборки мод будет в `build\\libs\\tokyoghoulrpg-1.2.0.jar`.
6. Положите JAR в `%appdata%\\.minecraft\\mods` и запускайте Forge 1.20.1.

Не переименовывайте папки `src`, `build.gradle` и `settings.gradle`.

## Версия 1.2.0 — CCG, NPC и способности
Добавлена полноценная серверная система ярости: разблокировка в древе за 5 очков, накопление от убийств и поедания мяса, шкала 0–100%, ульта на 60 секунд по клавише U, боевые бонусы и визуальная аура.


### Новое в 1.2.0

- Четыре пути: человек, гуль, полугуль и CCG.
- Для CCG добавлена отдельная прокачка: расследование, квинке, тактика, защита и дисциплина.
- Для CCG добавлен слабый аналог ярости — боевой дух на 30 секунд.
- Добавлены NPC гуля и следователь CCG.
- Гули автоматически атакуют любого игрока, который подходит близко.
- CCG автоматически атакует только чистых гулей; людей и полугулей не атакует без провокации. Если игрок ударил CCG, следователь отвечает.
- Добавлены яйца призыва NPC.
- Q — особая атака, E — рывок, F — восстановление.
- Исправлена передача серверных пакетов под Forge 1.20.1.
- Исправлен конструктор `DustParticleOptions` для Forge 1.20.1.
- Интерфейс и сообщения мода переведены на русский.
