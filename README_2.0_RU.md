# TokyoGhoulRPG 2.0.0

Это НОВАЯ версия. Рабочий проект 1.2.0 не заменяется и не изменяется.

### Первый фундамент 2.0
- красивый двухэтапный выбор происхождения;
- Human / Ghoul / Half-Ghoul / CCG;
- выбор Kagune для Ghoul: Rinkaku, Ukaku, Koukaku, Bikaku;
- выбор для Half-Ghoul: Rinkaku или уникальный Kagerō;
- CCG получает 5 стартовых очков;
- остальные начинают с 0 очков;
- уровень ограничен 30;
- характеристики ограничены 10;
- добавлена шкала голода;
- добавлено критическое кровотечение с 30-секундным таймером;
- добавлен серверный Kagune Grapple/Dash к точке прицеливания;
- Kagune/Quinque item models переведены на объёмную модель из elements;
- исправлена регистрация ClientSetup: mod events и Forge events разделены;
- добавлена команда `/tg skillpoints <amount>` для OP;
- добавлена команда `/tg level`;
- добавлена GitHub Actions сборка 2.0.

### Важно
Это **первый строительный этап 2.0**, а не заявление, что все запланированные 3D-анимации, NPC, боссы, квесты и Kakuja уже закончены. Они будут подключаться поверх этого фундамента следующими коммитами.

Финальная компиляция Forge 1.20.1 должна быть подтверждена GitHub Actions. Локально ForgeGradle в текущем окружении недоступен.
