# TokyoGhoulRPG 2.0.0 — новый проект

Это отдельная ветка разработки. Проект 1.2.0 не изменён.

## Уже заложено в фундамент 2.0
- максимум уровня 30;
- максимум обычных характеристик 10;
- CCG получает 5 стартовых очков, остальные начинают с 0;
- выбор типа Kagune хранится отдельно от происхождения;
- Rinkaku / Ukaku / Koukaku / Bikaku и уникальный Kagerō для Half-Ghoul;
- критическое состояние и таймер кровотечения;
- отдельная шкала голода для будущей UI-системы;
- Grapple/Dash packet для рывка к точке прицеливания;
- новый двухэтапный выбор происхождения и Kagune.

## Следующий визуальный слой
3D Kagune, модели Quinque, маски, одежда, боевые анимации и VFX подключаются поверх этого фундамента. Они намеренно не подменяются ванильным мечом.

## Проверка
Окончательную совместимость Forge 1.20.1 / 47.2.0 нужно подтверждать GitHub Actions. В текущем окружении нет ForgeGradle cache, поэтому локальный Gradle build здесь не заявляется как проверенный.
